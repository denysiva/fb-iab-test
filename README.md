# Тест панелі Facebook (fb-iab-test)

Тестова сторінка: чи можна згорнути панель вбудованого браузера Facebook на iPhone (X і «назад») і втримати її згорнутою, як це робить кошик UpsellGenie на threadythings.com.

- `index.html` — уся сторінка. `?v=a` — режим застосунку після першого свайпу людини. `?v=b` — сторінка сама плавно прокручується і вмикає режим одразу при завантаженні. `?v=b1`…`?v=b5` — інші способи прокрутки без людини: 1 px, стрибок на 600 px, якір, імітація свайпу кадр за кадром, фокус на полі вводу. Без параметра — вибір варіанта.
- Опубліковано на GitHub Pages: репозиторій `denysiva/fb-iab-test`.
- Результат 24.10.2026, iPhone 18 Pro, додаток Facebook: варіант A згортає панель Facebook, варіанти B і B1–B5 — ні. Сайт сам прокрутити сторінку так, щоб Facebook сховав панель, не може, потрібен свайп людини.
- Оновити: змінити `index.html`, зробити commit і push у `main`; GitHub Pages перезбирає сторінку сам.
