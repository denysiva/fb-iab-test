# Тест панелі Facebook (fb-iab-test)

Тестова сторінка: чи можна згорнути панель вбудованого браузера Facebook на iPhone (X і «назад») і втримати її згорнутою, як це робить кошик UpsellGenie на threadythings.com.

- `index.html` — уся сторінка. `?v=a` — режим застосунку після першого свайпу людини. `?v=c` — людина натискає кнопку, сайт сам прокручує сторінку і вмикає режим. `?v=d` — копія кошика threadythings: кнопка відкриває кошик без прокрутки, шапка й низ стоять, гортається лише список; журнал записує свайпи й зміни висоти екрана. `?v=b` — сторінка сама плавно прокручується і вмикає режим одразу при завантаженні. `?v=b1`…`?v=b5` — інші способи прокрутки без людини: 1 px, стрибок на 600 px, якір, імітація свайпу кадр за кадром, фокус на полі вводу. Без параметра — вибір варіанта.
- Опубліковано на GitHub Pages: репозиторій `denysiva/fb-iab-test`.
- Результат 24.10.2026, iPhone 18 Pro, додаток Facebook: варіант A згортає панель Facebook, варіанти B, B1–B5, C і D — ні. Сайт сам прокрутити сторінку так, щоб Facebook сховав панель, не може, потрібен свайп людини.
- Оновити: змінити `index.html`, зробити commit і push у `main`; GitHub Pages перезбирає сторінку сам.

## Лендінг 4490 — auto

Готовий лендінг: **https://denysiva.github.io/fb-iab-test/auto/**. Відкривати без параметрів: у мобільному браузері Meta за замовчуванням обирається `auto`. Він пробує розгорнути сторінку при завантаженні, повторює спробу кнопкою та залишає справжній свайп резервним шляхом. В інших браузерах без параметрів працює звичайна адаптивна верстка.

Користувач підтвердив роботу після прокрутки в Meta, відкривши лендінг без параметрів. Це підтверджує гілку зі свайпом у режимі `auto`; автоматичне приховування панелі без жесту або лише кнопкою на iPhone цим тестом не підтверджене.

- `auto/` — окрема копія готової версії `4490_landing_meta_v2` із збереженими текстами, фотографіями та інтеграціями.
- Інструкція й результати перевірок: [auto/README-UK.md](auto/README-UK.md).
- GitHub Pages призначений для тесту вигляду та браузера Meta. Оригінальні переходи до офера використовують маршрутизацію трекера; статичний хостинг її не замінює.
