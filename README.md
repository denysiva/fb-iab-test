# Тест панелі Facebook (fb-iab-test)

Тестова сторінка: чи можна згорнути панель вбудованого браузера Facebook на iPhone (X і «назад») і втримати її згорнутою, як це робить кошик UpsellGenie на threadythings.com.

- `index.html` — уся сторінка. `?v=a` — режим застосунку після першого свайпу людини. `?v=b` — сторінка сама прокручується і вмикає режим одразу при завантаженні. Без параметра — вибір варіанта.
- Опубліковано на GitHub Pages: репозиторій `denysiva/fb-iab-test`.
- Результат 24.10.2026, iPhone 18 Pro, додаток Facebook: варіант A згортає панель Facebook, варіант B — ні. Сайт сам прокрутити сторінку так, щоб Facebook сховав панель, не може, потрібен свайп людини.
- Оновити: змінити `index.html`, зробити commit і push у `main`; GitHub Pages перезбирає сторінку сам.
