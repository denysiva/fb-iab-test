# 4490 — адаптивна версія з режимом Meta IAB

Готова окрема версія для завантаження у ваш трекер. Оригінальну папку `4490_landing_archive` не змінено. У ZIP `index.html` лежить у корені, поруч із `files/`; збірка та встановлення пакетів не потрібні.

## Як тестувати

Після розміщення додайте до URL один із параметрів нижче. Якщо в URL уже є `?`, додайте параметри через `&`. Решту параметрів реклами та трекера залишайте.

| Параметри | Що перевіряємо |
| --- | --- |
| `?iab=auto&iab_debug=1` | Спроба при завантаженні → повторна спроба кнопкою → резервний справжній свайп. |
| `?iab=swipe&iab_debug=1` | Механіка A: тільки прокрутка пальцем угору, без автоматичної спроби та Fullscreen API. |
| `?iab=button&iab_debug=1` | На старті нічого не прокручується. Спроба після натискання NEXT/YES/NO; свайп залишається резервом. |
| `?iab=off` | Звичайна адаптивна версія без нового розгорнутого режиму. |

Без параметрів `auto` вмикається тільки при розпізнаванні мобільного Facebook / Instagram / Messenger. В інших браузерах працює звичайна верстка. Явний `iab=auto`, `swipe` чи `button` примусово вмикає експеримент і в інших браузерах. `iab_debug=1` показує маленький діагностичний рядок; при звичайному відкритті його немає.

Порядок перевірки на iPhone:

1. Відкрити `auto` саме з оголошення у Facebook. Почекати приблизно секунду без дотиків. Перевірити панель Facebook очима.
2. Якщо панель залишилася, натиснути NEXT. Перевірити панель знову.
3. Якщо вона залишилася, провести пальцем угору по сторінці. Потрібна реальна прокрутка документа щонайменше на 40 px. Горизонтальний свайп або свайп вниз від верхньої межі не є цим тригером.
4. Пройти всі сім кроків, перевірити вибір відповідей, повернути телефон горизонтально та вертикально. На короткому екрані або при збільшенні тексту вміст повинен залишатися доступним через прокрутку.
5. Після розгортання маленька кнопка `⌄` у правому верхньому куті повертає звичайну прокрутку. Повторне автоматичне розгортання до перезавантаження вимикається. Для Fullscreen API також працює стандартний вихід браузера / Escape.
6. Повторити з `swipe`, `button` і `off`. Між спробами відкривати сторінку заново, щоб не порівнювати різний стан уже згорнутої панелі.

Для точної перевірки механіки A починайте з `swipe`. Якщо 40 px у певній версії Facebook замало, можна порівняти `iab_threshold=80` або `120` — допустимий діапазон 40–160 px. Параметр не змінює тексти чи переходи.

## Що означає діагностика

- `armed` — документ доступний для нативної прокрутки, режим ще не зафіксовано.
- `load-fallback-swipe` / `button-fallback-swipe` — автоматична спроба не виявила приросту висоти; очікується свайп.
- `locked · native-scroll` — після справжнього жесту та прокрутки документа включено окремий прокручуваний шар.
- `locked · fullscreen-api` — браузер повідомив про вхід у стандартний повноекранний режим.
- `locked · load-viewport-heuristic` / `button-viewport-heuristic` — після програмного скролу висота видимої області зросла щонайменше на 24 px. Це непрямий сигнал, а не доказ прихованої панелі Facebook.
- `released` — користувач повернув звичайну прокрутку.

**Напис `locked` сам по собі не підтверджує приховування кнопок Facebook.** Він підтверджує тільки стан сторінки. Рішення щодо панелі приймає додаток Meta.

## Як це влаштовано

На початку документ має запас висоти для справжньої прокрутки. Лендінг закріплено біля верху через `position: sticky`, тому під час пробної прокрутки він не повинен стрибати. До першого жесту `body` не блокується.

Після справжнього вертикального жесту та потрібного зсуву документа додається `iab-locked`: HTML і body отримують `overflow: hidden`, а той самий `main` стає фіксованим шаром із власною прокруткою. Вміст не дублюється, обробники кнопок не перевішуються, позиція документа не скидається до нуля. Це адаптація механіки [вашого тесту A](https://denysiva.github.io/fb-iab-test/?v=a).

`auto` один раз пробує програмний скрол при завантаженні. Якщо висота не зростає, позиція відновлюється, сторінка залишається доступною для жесту. На кнопці додатково перевіряється стандартний `requestFullscreen`, якщо браузер його підтримує. Відмови обробляються без поломки квізу. Початок дотику скасовує незавершену автопробу, щоб вона не повернула сторінку назад під пальцем.

Стандартний Fullscreen API має обмеження підтримки й вимагає тимчасової активації користувачем: [документація MDN](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen). Тому автозапуск не видається за гарантований спосіб сховати панель Facebook. Висота верстки використовує динамічні одиниці екрана з резервом для старіших браузерів: [пояснення WebKit](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/).

## Збережено та виправлено

- Усі 12 JPG/WebP-файлів збережено побайтово; ті самі 9 посилань на зображення в HTML.
- Текст усередині лендінгу й усі 1080 рядків перекладів збережено. Виправлено лише помилкові назви 28 ключів заголовків та зайве присвоєння глобальної змінної у шведському словнику. В усіх 27 мовах тепер доступні всі 40 ключів; арабська отримує напрям справа наліво.
- Збережено `{offer}&sig=35`, ідентифікатор `ctabb`, `data-cta`, URL іконки та обидва зовнішні скрипти інтеграції. Їх завантаження більше не блокує розбір сторінки.
- Замість універсального 105-КБ пакета — невеликий код саме для цього семикрокового квізу. Прибрано запит до відсутнього `locales/lang.json` та помилку необробленого Promise.
- Прибрано посилання на відсутні шрифти, JPG-альтернативи та декоративні SVG. Наявні фото не замінювалися. Шрифт — системний sans-serif, який і використовувався як запасний у наданому неповному архіві.
- Прибрано поворот всієї сторінки на 90° та залежність розмірів тексту від масштабу всього документа. Додано верстку для горизонтального телефона, безпечні відступи біля вирізів екрана, доступне масштабування, мінімальні зони дотику 44 px, видимий фокус і підтримку зменшеного руху.
- Вибір до трьох відповідей працює також із клавіатури. Неактивні кроки приховані від фокуса та екранного читача. Замість блокування кнопок на 1,8 секунди — короткий захист від подвійного натискання.

Локальний HTML/CSS/JS скоротився з 214 894 до приблизно 88 000 байтів — на 59,1% без стиснення. Це розмір коду, а не виміряний приріст швидкості на мобільній мережі.

## Результати перевірки

- 84 перевірки верстки: 7 кроків × 12 розмірів — 320×568, 360×640, 375×667, 390×844, 393×852, 412×915, 430×932, 768×1024, 844×390, 667×375, 1280×720, 1920×1080. У цих перевірках немає горизонтального переповнення чи обрізаного тексту; кнопки вміщуються в екран.
- Ще 42 перевірки: 7 кроків × українська, німецька, французька, фінська, арабська й японська на 320×568.
- 13 автоматизованих перевірок логіки: автоспроба без ефекту, справжній / синтетичний / горизонтальний жест, поріг 40 px, масштабування, зміна орієнтації, переривання дотиком, кнопка без Fullscreen API, вихід, відновлення історії та фоновий стан. Це моделювання подій, а не емуляція нативного Facebook.
- У браузері перевірено переходи, ліміт трьох відповідей, зняття вибору клавіатурою, фінальний CTA, автоспробу з поверненням до свайпу, гілку Fullscreen API та кнопку відновлення прокрутки. У чистій вкладці нова версія не показала помилок JavaScript.
- Контрольними сумами підтверджено незмінність оригінальної папки та зображень у новій версії. Усі локальні залежності існують.

Перевірки розмірів виконано у настільному браузері, а не на фізичних пристроях. Автоматичне приховування нативної панелі Facebook на вашому iPhone, поведінку всіх версій Meta та швидкість на реальній мобільній мережі ще треба перевірити. Називати це гарантованим автоповноекранним режимом або «ідеальним на всіх телефонах» було б неточно.

## Зовнішні переходи та відкат

У вихідній версії `fb-simple_nopre.js` перехоплює фінальний CTA і Back. У локальній перевірці фінальний CTA сформував перехід на корінь домену з `sub_id_20=CTAbutton`. Це збережена зовнішня логіка, а не новий механізм розгортання. `iab=off` вимикає тільки наш режим; він не вимикає старий обробник Back. Зовнішні файли можуть змінюватися незалежно від цього архіву.

Для перевірки офера розміщуйте версію в середовищі вашого трекера. Звичайний статичний хостинг не підставляє `{offer}` та не замінює маршрутизацію трекера. Перевірка вигляду на GitHub Pages і перевірка повного рекламного переходу — різні перевірки.

Швидкий відкат нового режиму — `iab=off`. Повний відкат — повернути початковий архів, який залишився без змін.

Файли для подальшої роботи: `files/landing.css` — верстка; `files/app.js` — квіз; `files/iab-boot.js` і `files/meta-iab.js` — режим Meta; `files/script.js` — наявні переклади.
